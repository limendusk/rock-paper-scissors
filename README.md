# rock-paper-scissors

A rock paper scissors game that is played through three buttons on the screen, each corresponding to a choice.

A game is started when the user first clicks on any of the three choices. The user may click on the buttons repeatedly and the game will continue until either the user or the computer reach a score of 5. After the winner is announced, the next click on any of the choices will start a new game. A game may be ended at any time using the reset button, which will set the scores back to 0.
